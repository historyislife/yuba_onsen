# 湯迫温泉 白雲閣・健康村 再生プロジェクト 更新版 v3

## 開き方
配布ZIPをすべて展開し、index.htmlをブラウザで開いてください。HTML・CSS・Vanilla JavaScriptのみで動作し、インストールやビルドは不要です。
公開するときはindex.html、css、js、assetsを同じ階層のままアップロードしてください。

## ページ構成
ファーストビュー → プロジェクト → 健康村（第一段階：日帰り温泉・大衆演劇） → 白雲閣（第二段階：温泉旅館） → 湯迫温泉の記憶 → 再生の現在地 → Instagram → 運営主体 → お問い合わせ。
各セクションに固有IDがあり、後から独立ページへ分離できます。

## 編集箇所
- 文章・写真・運営情報：index.html内の該当セクション。HTMLコメントに編集時の注意点があります。
- 配色・幅・余白：css/style.cssの先頭の変数と各セクションのコメント。
- Instagramと問い合わせ：js/main.js先頭のSITE_CONFIG。正式なURLを設定済みです。変更時にはHTMLのリンクも合わせて修正してください。
- Instagramは正式なhttps URL、問い合わせは正式なhttpsフォームURLまたはmailto:メールアドレスを指定します。
- 現在・再生中・再生後の比較写真：index.htmlのphoto-comparisons。実際の写真と撮影日・説明を追加してhiddenを削除してください。

## 使用写真
提供された最新版 old_exterior(2).jpg / old_bath(2).jpg / old_stagehall(2).jpg / old_garden(2).jpg / old_interior(2).jpg をWebP形式のコピーとして使用。元画像は変更していません。
営業当時の写真として注記し、館内の位置・浴場の所属などは断定していません。
外観写真の元解像度は420×289pxです。大型表示では資料由来の粗さが残ります。より高解像度の原本があれば差し替え可能です。
一覧ではレイアウトに合わせて一部がトリミングされますが、拡大表示では写真全体を確認できます。

## 外部サービス
この配布版には外部フォント、アクセス解析、SNS埋め込み、Cookie、フォーム送信処理は含みません。
Instagramや外部フォームのリンクを設定した場合は、クリック時にそのサービスへ移動します。フォームで個人情報を集める段階で、利用目的・プライバシー方針・送信先を整理してください。

## 開発用構成
